# Missing features

The consolidated, honest list of what Saken does **not** do yet. Drawn from the
**2026-07-23 cross-repo audit** (`docs/AUDIT-2026-07-23.md`), the older **2026-06-14 project
audit**, the GitHub board, and the deferred-items section of the architecture reference.

<Callout type="info">
**Most of the old headline gaps have shipped**

This page used to lead with five missing capabilities. Four of them are now built. The
system also grew three surfaces it didn't have — a live NestJS backend, a superuser admin
console, and a React Native app — and then had all of it audited. Start with what closed.
</Callout>

## Deferred from the 2026-07-23 audit

The audit filed twelve findings (#82–#93) across four repositories — 0 Critical, 2 High, 9
Medium, 1 Low bundle — and **all twelve are fixed and closed**. What remains is the tail of
the low-severity hardening bundle (#93), judged not worth the churn during a cutover week:

| Item | Why it's not urgent | Why it should still land |
| --- | --- | --- |
| **No `helmet`** on the backend | API is JSON-only, consumed by known clients | Standard security headers are free |
| **Reminder cooldown is an in-memory `Map`** | Single instance today | Per-process ⇒ bypassable across instances; wants a `reminder_batches` table |
| **`round2` rounds negative exact-half-cents** toward `+∞` vs the web's `Intl` `halfExpand` | Reachable only for negative half-cent values | Silent divergence between two paths that are supposed to be identical |
| **Expo push token re-pointed on conflict** rather than reconciled | Self-heals via `DeviceNotRegistered` pruning | Correctness of multi-user shared devices |
| **`auth-context` builds a PostgREST `.or()` filter** by string interpolation | Inputs are JWT-derived, not user-supplied — not an injection vector today | Parameterise before that assumption changes |
| **Concierge backend path skips the attachment-path complex-prefix re-check** the web path performs | The write itself is still RLS-scoped | The two paths are meant to be behaviour-identical |

<Callout type="info">
**Two audit claims were wrong, and are recorded as wrong**

**The concierge-approval finding.** The audit claimed the backend's approval path kept the
submission's original `fiscal_year_id` instead of recomputing it from the admin-edited
`spentOn`. On reading the code, the recomputation was **already there and correct** — no
cross-FY misfiling was possible. A narrower real bug was found in the same code (the FY was
written *unconditionally*, so an approval with no `spentOn` silently relocated the expense
to the active year) and fixed. The issue was closed with the correction recorded rather than
quietly dropped.

**The JWT-pinning entry.** The audit's deferred list carried "JWT issuer/audience/algorithms
not pinned". That was accurate when the audit was written but **stale by the time the
document shipped** — the pinning was implemented in the same backend change as the rest of
the hardening bundle and went to production with it, while the deferred list was not
updated. `verifyAccessToken` pins issuer, audience, and algorithms today. Corrected in the
audit document on 2026-07-24; it is not a deferred item and never reached production
unpinned.
</Callout>

## Engineering debt carried over

From the 2026-06-14 audit, **not** re-litigated by the 2026-07-23 pass. None block the pilot;
address before scaling past a handful of buildings.

| Item | What |
| --- | --- |
| **H-P1** | Money aggregations pull every row into JS — should be SQL aggregates |
| **M-P1** | No pagination on `/payments`, `/expenses`, `/resident/expenses/all` |
| **M-P3** | Sequential dashboard fetches that could be `Promise.all`'d |
| **M-P4** | Synchronous, uncapped PDF generation |
| **M-C1** | Admin/resident detail pages are near-verbatim clones (drift risk) |
| **M-C4** | "Payments" (code) vs "Collections" (UI) naming split |
| **M-C7** | Budget-version snapshot failure is logged and swallowed |
| **M-S2** | `apartments.share ≤ 1000` cap contradicts the relative-weights model |
| **M-S4** | Dead columns + dead tables to drop in one cleanup migration |
| **L-S1** | `send-otp` edge function falls back to an **unverified** JWT decode and skips verification entirely when `SEND_OTP_HOOK_SECRET` is unset — an SMS-pump vector. Fail closed **before** enabling phone auth. |

Several higher-severity items from that audit were fixed after it was written (phone
uniqueness, the `roles_readable` leak, empty-string identity, the missing test suite, the
untyped client) — see [Status](/introduction/status).

## v2 backlog

Parked by design, and still parked: online payments / bank integration, multi-currency
(LBP), tenant-vs-owner modelling, per-building category management, a configurable
late-payer flag, system-calculated late fees, custom date-range PDF reports, year-over-year
comparison reports, in-app announcements / chat, and voting & decision logs.

Two items that used to live here have shipped: **push / in-app notifications** and an
**Arabic UI**.
