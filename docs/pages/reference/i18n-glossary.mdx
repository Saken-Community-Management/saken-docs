# Arabic translation glossary (i18n)

Exact English → Arabic pairing for **every** localized string in the Saken
web app (`saken`). This is a review/reference artifact — it documents the
translations; it is **not** a translation of this docs site.

:::warning[AI first pass — pending native review]
The Arabic below is **formal Modern Standard Arabic (فصحى)** — an AI-generated
first pass tagged `"_status": "ai-pending-native-review"` in each
`messages/ar/*.json`. A native Arabic speaker should review it before Arabic is
exposed to real users. (An earlier Levantine/Lebanese pass was replaced by this
formal-Arabic set on the `feat/arabic-msa` branch.)
:::

**Source:** `saken/messages/<en|ar>/<namespace>.json` (next-intl catalogs),
paired by key. **How the app picks a locale:** per-user, via a `saken-locale`
cookie (no URL routing); `users.language` is the source of truth.
