# Saken [The shared ledger for residential communities]

**Saken** is a shared-ledger and budgeted-operations web app for Lebanese residential
buildings and complexes (5–100 apartments). One resident — the **admin** — runs the
books. Every other resident can see what they owe and where the money went. A
**concierge** submits expenses for approval, and an optional **treasurer** shares the
admin's financial duties.

This site is the comprehensive documentation for the whole Saken project: the Next.js
web app (`saken`), the standalone NestJS backend (`saken-server`), and the MCP server
(`saken-mcp`) — written from the source, with an honest account of what ships today and
what is still on the roadmap.

:::tip[Documenting an MVP, honestly]
Saken is a **pilot-stage MVP**. Core flows are production-tested, but several
advertised capabilities are partial or stubbed. Throughout these docs, missing or
incomplete features are called out loudly rather than glossed over. Start with
[Status & maturity](/introduction/status) for the unvarnished picture.
:::
